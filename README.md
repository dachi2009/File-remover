EasyFileRemover

Software Introduction
This tool is used to automate file deletion efficiently. It allows the user to either securely delete files by shredding them first, or delete them normally without shredding.

This project is made for personal and learning purposes only. It is not intended to be a professional or production-level tool.

How to Use
Run the script using Python 3:
```bash
python3 easyFileRemover.py
```
All instructions and inputs are printed directly inside the script, so make sure to read everything carefully while using it.

Warning
ATTENTION: This tool is capable of deleting system files and files owned by root.
The creator takes NO responsibility for any data loss, system breakage, or misuse.
Always double-check file paths before confirming deletion.
